# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, exposed credentials, or user data in a public GitHub issue.

Report the issue privately to the repository owner with:

- A concise description and affected area
- Reproduction steps or a proof of concept
- The expected security impact
- Any suggested mitigation

Until a private reporting address is published, contact the repository owner through their private GitHub contact channel. Do not include real Gmail content, OAuth tokens, session cookies, or API keys in the report.

## Supported versions

This project is in active development. Security fixes are applied to the latest version on the default branch.
